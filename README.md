Barcelona Freelance Web Studio

## How to Use This Template

### Starting a New Client Project

1. Copy this entire folder
2. Rename it to the restaurant name (e.g. `el-raco-tapas`)
3. Open it in VS Code
4. Update the **Current Project Info** section at the bottom of `CLAUDE.md`
5. Type `/new-restaurant` in Claude Code and provide the restaurant details
6. Claude will generate your complete `index.html` to start from

---

## Available Claude Commands

| Command | What It Does |
|---|---|
| `/new-restaurant` | Builds a full restaurant site from scratch |
| `/new-section [type]` | Adds a new section to an existing page |
| `/fix-mobile` | Audits and fixes all mobile issues |
| `/review` | Full pre-delivery quality checklist |
| `/translate [language]` | Translates site to Spanish, Catalan, or English |

---

## Workflow for Every Project

1. `/new-restaurant` → generates the base site
2. Customize with real photos, content, colors
3. `/fix-mobile` → ensure everything works on phone
4. `/review` → pre-delivery audit
5. Deploy to Netlify
6. Connect client's custom domain

---

## Hosting & Deployment

- **Hosting:** Netlify (free tier for basic sites)
- **Domains:** Namecheap (~€10/yr)
- **Deploy:** Drag & drop the project folder to netlify.com/drop
